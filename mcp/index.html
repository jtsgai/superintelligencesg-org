SI Commons Connector — Documentation

Last updated: 28 October 2026

Endpoint: https://si-commons-mcp.superintelligencesg.workers.dev/mcp (MCP over Streamable HTTP, hosted on Cloudflare Workers)

Operator: JT M&C PTE. LTD. (UEN 202424056N), Singapore ("we"). Contact: info@jt-sgai.com

Overview

The SI Commons connector is a read-only Model Context Protocol server for the public Superintelligence SG directory of Singapore AI organisations. It cannot create, change or delete anything.

Tools

  • search_sg_ai_orgs: Search public organisation records. Optional filters: query (at most 120 characters), kind, lens, origin (curated or commons), sort (name or updated) and limit (1–50, default 10). Returns matching records and the total match count. Read-only.
  • get_org: Return one organisation record by its id, including evidence history when the directory has it. Unknown ids return not_found. Read-only.
  • ecosystem_stats: Return public counts: total records, counts by type and counts by kind. The stats endpoint has no record date, so as_of is null. Read-only.
  • recent_changes: Return the latest change records, newest first, with title, summary, date, evidence status and source URL. Includes records still marked needs_review. Read-only.
  • match_sg_ai_partners: Rank organisation records against a stated need using only each record's name, kind, founder and description, with a short reason for each match. Listings affiliated with the founder are labelled and get no ranking boost. Read-only.

Authentication

Every request needs an API key that we issue, sent as an HTTP header: Authorization: Bearer <your-key>. Keys are not published. To request access, email info@jt-sgai.com. Keep your key confidential.

Rate limits

Up to 60 requests per minute per API key. Above that, the server returns HTTP 429 with a Retry-After header giving the seconds to wait.

Errors

  • HTTP 401 unauthorized: the API key is missing or invalid.
  • HTTP 429 rate_limited: rate limit exceeded; retry after Retry-After seconds.
  • HTTP 503 not_configured: the environment has no API key configured.
  • Tool error invalid_argument: an argument failed validation.
  • Tool error not_found: the requested record does not exist.
  • Tool error upstream_unavailable: the directory API request failed; retryable.
